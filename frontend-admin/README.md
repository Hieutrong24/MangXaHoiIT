# IT Social Admin UI

Giao diện quản trị React + Vite cho các module:
- Dashboard tổng quan
- Người dùng
- Hoạt động người dùng
- Tuyển dụng
- Bài tập code và submissions

## Chạy dự án

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Cấu hình

Tạo file `.env` từ `.env.example` và chỉnh `VITE_API_BASE_URL` theo backend thực tế.

## Ghi chú

- UI đã bám theo bộ layout HTML mẫu trong file stitch.
- Nếu backend chưa đủ endpoint, giao diện vẫn giữ sẵn cấu trúc trang và form để bạn nối API sau.
